# HITEN — Personal Portfolio

Personal portfolio website for Hiten — CS student, surveillance operations leader, and aspiring DevOps & Infrastructure Engineer.

## 🚀 Deploy to GitHub Pages

1. Create a new GitHub repository (e.g. `hiten-portfolio` or `yourusername.github.io`)
2. Upload all files from this folder to the repo
3. Go to **Settings → Pages**
4. Under **Source**, select `main` branch and `/ (root)` folder
5. Click **Save** — your site will be live at `https://yourusername.github.io`

## 📁 Files

- `index.html` — The complete portfolio (self-contained, no build step needed)
- `README.md` — This file
